# BPDL - BeatSaver Playlist Downloader

## Overview
A simple CLI tool that automatically downloads and unpacks a .bplist file.

Written in rust🦀

## Installation
```bash
cargo install --release
```

## Usage
```bash
bpdl playlist.bplist
bpdl --overwrite -o my-playlist another-playlist.bplist
```
